# Projet Vault

> Groupe: Mael, Victor, Urllanda, Gabriel

Ceci est un projet de site web, un réseau social centré sur la Pop-culture.

## Mise en place

Pour mettre en place le projet sur votre machine :

1. Recréation de la base de donnée : Installez un serveur `MySQL` puis exécutez le script `./sql/setup.sql`. Celui-ci va créer une nouvelle base de donnée `vault`.

2. Le site est statique pour le moment, pour acceder au site : Ouvrez simplement le fichier `index.html`.
